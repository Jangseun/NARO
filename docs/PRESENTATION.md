- 실제로 테스트하지 않은 기능은 "완성"으로 쓰지 않습니다.

## 슬라이드 2. 제작 동기

**화면:** 문제 3가지를 아이콘으로
- 면접 연습을 도와줄 사람과 시간이 부족하다
- 내 표정, 고개, 자세가 어떻게 보이는지 스스로 알기 어렵다
- 답변 내용에 대한 구체적인 피드백을 받기 어렵다

> **대본:** 면접을 준비할 때 답변은 외울 수 있지만, 실제로 말할 때 제가 어디를 보고 있는지, 고개가 숙여져 있는지는 스스로 알기 어려웠습니다. 친구나 선생님께 부탁하려면 시간도 맞춰야 했습니다. 그래서 카메라가 제 자세를 대신 봐 주고, AI가 답변을 봐 주는 시스템을 만들고 싶었습니다.

```
Raspberry Pi Camera → 영상 인식 → 자세 분석 → 면접 피드백
```

> **대본:** NARO의 핵심은 이 흐름입니다. 라즈베리파이 카메라로 면접 보는 모습을 찍고, 영상에서 얼굴을 인식해서 고개 방향과 자세를 분석한 뒤, 그 결과를 면접 피드백으로 돌려줍니다. 여기에 AI가 자기소개서를 바탕으로 질문을 만들고 답변을 평가하는 기능을 더했습니다.

## 슬라이드 4. 왜 Raspberry Pi인가?

- 카메라를 직접 연결해서 **기기 안에서 영상 처리**
- 작고 저렴해서 책상 위 **면접 연습 장치**로 사용 가능
- 영상이 외부 서버로 나가지 않음 → 개인정보 보호
- **[사진: 라즈베리파이 + 카메라 모듈 설치 모습]**

> **대본:** 라즈베리파이를 사용한 이유는, 카메라를 바로 연결해서 영상 처리까지 기기 안에서 할 수 있기 때문입니다. 영상은 외부로 보내지 않고 라즈베리파이 안에서 분석하고, 분석한 숫자만 웹 화면으로 보냅니다.

## 슬라이드 5. 영상 인식 ① 얼굴과 특징점 검출 ★

**화면:** 분석 화면 캡처 (얼굴 박스 + 점 5개가 보이는 장면)
- OpenCV **YuNet** 얼굴 검출 모델 (딥러닝, 약 230KB)
- 찾는 것: 얼굴 위치 + **특징점 5개** (두 눈, 코끝, 입 양 끝)
- 640×480 영상을 실시간 분석: **[라즈베리파이 FPS 측정값]** FPS (PC 웹캠에서는 약 12~15 FPS)

> **대본:** 먼저 영상에서 얼굴을 찾습니다. OpenCV에 들어 있는 YuNet이라는 딥러닝 모델을 사용했는데, 얼굴 위치와 함께 두 눈, 코끝, 입 양 끝, 이렇게 다섯 개의 특징점을 찾아 줍니다. 화면에 보이는 파란 점들이 그 특징점입니다.

---

## 슬라이드 6. 영상 인식 ② 특징점으로 자세 계산 ★

**화면:** 얼굴 그림 위에 선을 그린 설명도 3개

| 측정 | 방법 |
|---|---|
| 고개 기울기 | 두 눈을 이은 선의 각도 |
| 좌우 회전 | 코끝이 두 눈 가운데에서 벗어난 정도 |
| 고개 숙임/듦 | 눈과 입 사이에서 코끝의 높이 |
| 위치·거리·움직임 | 얼굴 중심, 얼굴 크기, 위치 변화량 |

- 거리에 상관없이 비교하려고 **눈 사이 거리로 나눔**
- 고개 방향 추정이며, 눈동자 시선 추적은 아님

> **대본:** 특징점을 찾고 나면 간단한 수학으로 자세를 계산합니다. 두 눈을 이은 선이 기울어지면 고개가 기운 것이고, 정면을 보면 코끝이 두 눈 가운데에 있지만 고개를 돌리면 한쪽으로 치우칩니다. 카메라에서 멀어지면 얼굴이 작아지기 때문에, 눈 사이 거리로 나눠서 거리와 상관없이 비교할 수 있게 했습니다. 다만 이것은 고개 방향을 추정하는 것이고, 눈동자를 추적하는 시선 추적은 아닙니다.

## 슬라이드 7. 영상 인식 ③ 면접 피드백으로 활용 ★

**화면:** 결과 페이지의 "영상 분석 결과" 부분 캡처
- 면접 중 모든 프레임의 분석 결과를 **질문별로 모아 요약**
- 정면 응시 비율, 고개 숙임 비율, 기울어짐 비율, 움직임 지수 → **자세 점수**
- 규칙 기반 조언 + AI 종합 피드백에도 반영

> **대본:** 면접이 진행되는 동안 매 프레임 분석 결과를 모아 둡니다. 질문 하나가 끝날 때마다 그 질문에 답하는 동안 정면을 본 비율, 고개를 숙인 비율 같은 통계를 계산해서 저장합니다. 면접이 끝나면 이 결과로 자세 점수와 조언을 보여 주고, AI에게도 함께 전달해서 종합 피드백에 자세 이야기가 들어가도록 했습니다.

## 슬라이드 9. 시연 흐름

**캡처 순서:** 자료 관리 → 영상 분석 → 면접 설정 → 면접 진행(카메라 옆에) → 결과 → 성장 분석

1. 자기소개서 등록
2. 카메라 켜고 실시간 분석 확인
3. 기업·직무 입력 → AI 질문 생성
4. 질문에 답하는 동안 자세 분석
5. 결과: 답변 피드백 + 자세 분석

> **대본:** 실제 사용 순서입니다. 먼저 자기소개서를 등록하고, 카메라를 켜서 얼굴이 잘 인식되는지 확인합니다. 지원 기업과 직무를 입력하면 AI가 질문을 만들고, 질문에 답하는 동안 오른쪽에서 카메라가 자세를 분석합니다. 면접이 끝나면 답변 피드백과 자세 분석 결과를 함께 볼 수 있습니다.

## 슬라이드 10. 개발 중 문제와 해결

| 문제 | 해결 |
|---|---|
| 윈도우에서 한글 폴더 경로의 모델 파일을 OpenCV가 못 읽음 | 파일을 numpy로 읽어 메모리로 전달 |
| 라즈베리파이의 picamera2와 최신 OpenCV의 numpy 버전 충돌 | OpenCV 버전을 고정(4.10)하고 같은 결과가 나오는지 테스트 |
| 카메라 처리와 웹 요청이 동시에 필요 | 카메라는 별도 스레드에서 계속 분석, 웹은 최신 결과만 가져감 |
| 브라우저 `<img>`는 로그인 헤더를 못 보냄 | 영상 주소에 토큰을 붙여 확인 |
| API 키가 없을 때 시연 불가 | 데모 모드를 만들고 화면에 "데모 모드"로 구분 표시 |

> **대본:** 개발하면서 몇 가지 문제가 있었습니다. 가장 기억에 남는 것은 컴퓨터 폴더 이름에 한글이 있어서 OpenCV가 모델 파일을 못 읽은 문제였는데, 파일을 직접 읽어서 메모리로 넘기는 방법으로 해결했습니다. 또 카메라 분석과 웹 요청을 동시에 처리하기 위해 카메라를 별도의 스레드에서 돌리도록 했습니다.
