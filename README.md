# NARO (나로)

### 가장 나다운 모습으로 나아가다.

**NARO**는 AI 기반 모의면접 및 면접 습관 분석 서비스입니다.

사용자가 혼자서도 실전과 유사한 모의면접을 진행하고, 자신의 답변 내용뿐만 아니라 시선 처리, 자세, 말하기 습관 등을 객관적으로 확인하고 개선할 수 있도록 돕는 것을 목표로 합니다.

## 프로젝트 소개

면접을 준비하는 학생들은 예상 질문에 대한 답변을 작성하고 암기하지만, 실제 면접에서 자신의 말투나 시선, 자세가 어떻게 나타나는지 파악하기는 어렵습니다. 또한 친구나 선생님과 모의면접을 진행하려면 시간과 장소를 맞춰야 하는 어려움이 있습니다.

NARO는 이러한 문제를 해결하기 위해 **언제든 혼자서 모의면접을 연습하고, AI 분석을 통해 자신의 면접 습관을 돌아볼 수 있는 환경**을 제공하고자 합니다.

## 주요 기능 (개발 예정)

### 1. AI 맞춤형 모의면접
- 자기소개서 및 포트폴리오를 기반으로 맞춤형 면접 질문 생성
- AI를 활용한 답변 분석 및 개선 방향 제안
- 실제 면접을 가정한 모의면접 진행

### 2. 비언어적 행동 분석
- Raspberry Pi Camera를 활용한 실시간 영상 수집
- MediaPipe와 OpenCV를 활용한 시선 방향 및 자세 분석
- 면접 중 나타나는 습관을 분석하여 피드백 제공

### 3. 말하기 습관 분석
- PC 마이크를 통한 면접 답변 녹음
- Whisper 기반 음성 텍스트 변환(STT)
- 불필요한 추임새, 답변 길이 등 말하기 습관 분석

### 4. AI 면접 피드백
- 답변 내용과 비언어적 행동 분석 결과 종합
- 사용자별 면접 피드백 리포트 제공
- 개선이 필요한 습관과 연습 방향 제안

## 기술 스택

| 구분 | 기술 |
|---|---|
| Frontend | React, JavaScript |
| Backend | Python, FastAPI |
| AI | OpenAI API, Whisper, MediaPipe |
| Computer Vision | OpenCV |
| Hardware | Raspberry Pi, Raspberry Pi Camera |
| Data Visualization | Chart.js |

※ 기술 스택은 개발 과정에서 변경될 수 있습니다.

## 시스템 구성

**사용자 웹 브라우저 (React)**
- 자기소개서 및 포트폴리오 입력
- 실시간 모의면접 화면 제공
- PC 마이크를 통한 음성 입력
- 면접 분석 결과 확인

**백엔드 서버 (FastAPI)**
- 프론트엔드와 분석 모듈 간 데이터 통신
- AI 면접 질문 및 피드백 생성
- 음성 데이터 처리 및 분석 결과 통합

**Raspberry Pi**
- 카메라 영상 수집 및 실시간 스트리밍
- 얼굴 및 자세 관련 데이터 분석
- 분석 결과를 백엔드와 연동

## 기대 효과

- 반복적인 모의면접을 통한 면접 준비 부담 완화
- 자신의 면접 습관에 대한 객관적인 피드백 제공
- 학생들이 자신의 경험과 역량을 자신 있게 표현할 수 있도록 지원
- 웹, AI, 컴퓨터 비전 및 임베디드 시스템을 연계한 개발 경험 축적

## 향후 계획

- 사용자 계정 및 면접 기록 저장 기능
- 이전 면접 결과와 비교할 수 있는 성장 그래프
- 직무별 맞춤형 면접 연습 기능
- 발표 연습 모드로 서비스 확장
